Milestone 2 · Analysis pipeline

Auto Scanner Organizer

Scanned pages land in a staging folder. Apple Vision reads the text on the Mac, Claude splits the stack and chooses a vault folder with read-only tools, and each document is filed into your Obsidian vault as a searchable PDF with a Markdown note. In Milestone 2 the pipeline runs from the scan-organizer command line; the Mac app with scanning arrives in Milestone 3.

Deployment Decisions

1. Requirements

  • macOS 26 with Xcode 26.6 (Swift 6.3) installed and opened once to accept its license.
  • Homebrew.
  • An Anthropic API key (see Environment variables).

2. Set up and check

make init    # brew bundle: swiftlint, swiftformat, xcodegen
make check   # SwiftLint --strict, then every test (no network access)

Other targets: make test, make lint, make format, make teardown, make test-live, and make cli ARGS="…".

3. Environment variables

4. Run the pipeline

swift run --package-path packages/ScanCore scan-organizer process \
  --staging ~/Documents/Scans/Staging \
  --vault "~/Library/Mobile Documents/iCloud~md~obsidian/Documents/Vault" \
  --watch
CommandWhat it does
process --staging <dir> --vault <dir> [--watch] Processes every ready batch once, or keeps watching. Options: --model sonnet|opus|haiku or --model claude-sonnet-5|claude-opus-5|claude-haiku-4-5, --threshold 0.5–1.0 (default 0.75), --data <dir>.
status [--data <dir>]Lists every batch, most recent first, with documents that need attention.
review <batch> <doc> --staging … --vault … --folder <path> Files a document from Needs review. Optional corrections: --subfolder, --title, --from, --date YYYY-MM-DD, --amount 12.50, --currency USD, --accept-duplicate.
retry <batch> --staging … --vault …Resumes a failed batch from the step that failed.

One command at a time. process, review, and retry lock the data directory, so only one of them can run against it at a time. Stop process --watch (Control-C) before running review or retry. status only reads, so it is always safe.

5. The staging folder

Staging/
  2026-09-13-224203/        a scanner batch
    page-001.png …
    batch.json              written last; marks it ready
    .scancore/              saved steps, so it can resume
  drop-2026-09-14-013006/   a dropped file, adopted after 5 s
  _done/                    batches with every document filed

Drop .pdf .png .jpg .jpeg .heic .tiff files at the staging root to process existing scans. Folders starting with . and _done are ignored.

6. What lands in the vault

  • PDF: the scanned pages with an invisible, searchable text layer.
  • Note: YYYY-MM-DD From - Title.md with properties, a summary, handwritten notes, key facts, related notes, and the extracted text. Account, card, and Social Security numbers are reduced to their last four digits.
  • Ledger: for batches with a purpose, a ledger note such as 2026 Business Receipts.md in the purpose's folder, with one row per document and a total.

A document goes to Needs review instead when a split or folder is uncertain, it would create a new top-level folder, it doesn't fit the purpose, an amount is missing, it looks like a duplicate, the ledger needs attention, Claude declined or answered invalidly, or the chosen folder no longer exists. status shows the reasons.

7. Where state is kept

~/Library/Application Support/AutoScannerOrganizer/ holds events.jsonl (the append-only history of every batch, including tokens and estimated cost per Claude request) and purposes.json (remembered purpose folders and recent purposes). It also holds scan-organizer.lock, which process, review, and retry hold while they run so only one pipeline command uses the folder at a time; status doesn't need it. Change the folder with --data.

8. Manual steps

  1. Create the API key and export ANTHROPIC_API_KEY.
  2. Choose a staging folder and make sure your vault folder is downloaded locally (in Finder, choose Download Now on iCloud folders).

9. Troubleshooting

error: Set ANTHROPIC_API_KEY…Export the key in the shell that runs the command.
error: another scan-organizer command is using …Another process, review, or retry is using the same data directory. Stop it (Control-C in its terminal), then run your command again.
failed at … http(status: 401 …)The key is wrong or revoked; create a new one, then run retry.
failed at … 429 or 529Rate limits and overloads are retried three times automatically; run retry later.
Claude declined (…)Resolve the document with review.
the ledger rejected the row: …Repair the ledger note (for example, a mixed currency), then run review with any existing --folder. The document's PDF and note are already filed, so folder and amount corrections don't apply; only the ledger row is retried.
Vault write failuresiCloud placeholders or permissions: download the folder, check access, then retry. No partial files are left behind.
batch.json is unreadableThe scanner stopped mid-write; fix or remove that batch folder.

10. Live tests

make test-live sends a synthetic four-page stack and one placement to Claude (a few cents per run). It needs ANTHROPIC_API_KEY; ordinary make test never touches the network.
